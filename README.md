Övning 1 API – Entity Framework Core - Lagersystem - StorageApi
- Nytt projekt: ASP.NET Core Web API (.NET 10) med namn StorageApi

  
Del 5 Efter Scaffold, frågor:
Hur används StorageContext?
StorageContext är länken mellan StorageApi applikationen och databasen. 

Hur fungerar CreatedAtAction, Ok, NotFound osv?
CreatedAtAction(), Ok() och NotFound() är så kallade ActionResult-metoder och används för att för att skicka tillbaka HTTP-svar från en Controller till klienten (exempelvis Postman).
